# 可视化实现说明

## 1. 任务目标

本任务为纯可视化任务，不涉及模型训练。目标是根据 Hi-C / Micro-C 接触矩阵与基因注释数据，绘制基因组浏览器风格的多轨道图，直观展示不同实验条件下基因组各位点的接触强度变化，并与基因位置、已知染色质结构区间对齐。

每张图覆盖固定区间（10,000 bp），按序排列以覆盖整个大肠杆菌基因组（约 4.64 Mb）。

---

## 3. 绘图方法

### 3.1 整体布局

采用 matplotlib gridspec 分为四个面板，共享同一 X 轴（基因组位置 bp），自上而下：

| 面板 | 内容 |
|---|---|
| 第 1 层 | 三条条件的接触强度曲线 + 两条阈值虚线 |
| 第 2 层 | 三条件平均信号（灰色填充） |
| 第 3 层 | 基因轨道（蓝色色块，标注基因名） |
| 第 4 层 | 结构轨道（CHIN 橙色 / CHID 紫色 / OPCID 黄色，标注编号） |

### 3.2 接触强度计算

对每个 .cool 文件，取全基因组稀疏矩阵，计算每个 bin 的行和（该 bin 与全基因组其他位点的总接触次数），开平方根后按总 reads 数归一化。归一化的目的是消除三个条件测序深度不同带来的绝对值差异，使曲线可以直接横向比较。

### 3.3 曲线平滑

原始 10 bp 分辨率曲线锯齿严重，采用窗口为 50 bins（约 500 bp）的移动平均进行平滑，使趋势更清晰。

### 3.4 阈值虚线

基于平均信号的统计分布自动计算两条阈值：
- Primary threshold = 均值 + 1 倍标准差
- Secondary threshold = 均值 + 2 倍标准差

超过阈值的区域提示接触强度异常偏高，值得关注。

### 3.5 标签位置处理

结构区间常跨越多张 10 kb 图。当某个结构条只在当前图中露出一小段时，其标签若按整条区间中心放置会跑到图外，造成大片空白。处理方式：标签放置在该结构在当前图内可见部分的中心；若中心超出图边界，则自动钳制到距离最近的边缘（留 3% 边距），保证标签始终在图内。

## 5. 结构重叠关系分析

对三个标注表做区间重叠统计：

| 关系 | 重叠数 | 总数 | 比例 |
|---|---|---|---|
| CHID 落在 CHIN 范围内 | 25 | 26 | 96% |
| CHIN 落在 CHID 范围内 | 101 | 250 | 40% |
| OPCID 与 CHIN 重叠 | 9 | 68 | 13% |
| OPCID 与 CHID 重叠 | 0 | 68 | 0% |

结论：

1. **CHID 几乎完全包含在 CHIN 中**（96%），与"CHID 由多个 CHIN 聚集而成"的定义一致。但并非所有 CHIN 都成团，只有 40% 的 CHIN 属于某个 CHID 簇。
2. **OPCID 与 CHID 完全不重叠**，与二者生物学位置不同有关：OPCID 出现在高转录基因区域，CHIN/CHID 出现在非转录区域。
3. OPCID 与 CHIN 仅有少量重叠（13%），说明二者总体上是独立的结构类型。
